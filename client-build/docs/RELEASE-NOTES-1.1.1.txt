BALAJI FEEHUB CLIENT 1.1.1 - RELEASE NOTES
==========================================

Installer:  BalajiFeeHub-Client-Setup.exe               (per-machine, Program Files, Windows x64)
Portable:   BalajiFeeHub-Client-Windows-x64.zip         (extract and run, no installer)
Version:    1.1.1 (previous: 1.1.0 offline-first build, 1.0.2 original client)
Hashes:     see SHA256SUMS.txt in the same folder.

Not used: the old .bcupdate client-update package. It is incompatible with this
release (it replaces app.asar of the old remote-loading shell).

1. WHAT THIS CLIENT DOES
------------------------
- Opens its own bundled screens from BalajiFeeHub.exe. The Main Server is not
  needed to open the program.
- Server address is kept in %APPDATA%\BalajiFeeHub\config.json (default
  192.168.0.116 port 8001). Change it in File > Server Settings. No restart needed.
- Offline sign-in for users who have signed in on this PC before. The password is
  never stored; only a salted PBKDF2 verifier, valid 90 days after the last online
  sign-in. Wrong passwords are refused.
- Cached data (IndexedDB): student search and view, fee position and ledger as of
  the last sync, master data, bus master (read only).
- Offline creates, queued and marked Pending Sync: receipts, expenses, bills.
- Receipt numbers are assigned by the server at sync, using the same counters
  as the online screens. Nothing is numbered on the PC.
- Connection badge: Connected / Synced <time>; Syncing / N pending;
  Offline / Server unavailable / N waiting; Sign in to sync; Sync problem.
- Automatic reconnect: the client probes the server every 3-30 seconds while
  offline and resumes at once. No restart and no Sync button are needed.
- Duplicate-safe sync: every queued item has an ID that is re-sent on retry,
  and the server applies each ID once. A payment already waiting on the PC is
  not queued a second time.
- Server-only screens (admin, settings, fee structure changes, bus master
  edits, device administration, Master PIN, user roles) show a notice offline.
  Any other write made offline is refused before it leaves the PC.
- Student version field support (conflict detection preparation).
- Backend sync changes included: bus routes and student version in the sync
  snapshot; version increment on student profile edits.

3. KNOWN EXCEPTIONS (imported, but a field needs review)
--------------------------------------------------------
- 2 fee amounts with no exact existing fee structure (admission 3932: Excel 17,500
  vs FeeHub 15,000; admission 1022: Excel 22,500 vs FeeHub 14,500). The students are
  imported and keep their FeeHub structure. The Excel fee is in the fee record.
  The displayed total follows the structure until a structure is confirmed.
- 156 zero-fee Excel rows for existing students: FeeHub fee kept (see above).
- 356 Excel "Bus From" values not matched to exactly one bus stop (276 not found,
  80 area shared by several stops). Those students are imported; bus is unchanged;
  the raw Excel value is in source_bus_from.
- 10 identical duplicate fee-structure records already exist in FeeHub. Not deleted.
- Section letters differ between Excel and FeeHub for some classes (example:
  Class 1 English). Sections changed only where the mapping was exact.
- Full list: fee-import-exceptions.csv and fee-import-final-report.md.

5. LIMITATIONS
--------------
- Offline sign-in uses the password saved on this PC: a password changed on the
  server is accepted offline with the old password until the next online sign-in.
- Role or permission changes take effect at the next online sign-in.
- The sign-in session lasts 12 hours. After that, queued items wait for a sign-in
  ("Sign in to sync"). They are not lost.
- Offline receipts show no number until they are synced.
- The sync pulls a full snapshot (about 2,300 students) every 30 seconds while
  connected. It has not been load-tested on a LAN with many clients.
- Clean Windows PC: the client bundles its own runtime, but the installer was
  tested on the development PC with a per-user build of the same package. It is
  not yet tested on a clean PC or with the administrator-mode installer.
